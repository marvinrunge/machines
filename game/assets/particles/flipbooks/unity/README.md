# Unity Labs VFX flipbooks (CC0)

Pre-assembled flipbook sheets from Unity Technologies' "Free VFX Image Sequences & Flipbooks" (Thomas Iché, 2016),
released under CC0 1.0 (https://creativecommons.org/publicdomain/zero/1.0/):
https://unity.com/blog/engine-platform/free-vfx-image-sequences-flipbooks

Converted from the TGA sheets in `<set>-flipbooks.zip` to PNG, otherwise unchanged. Used by game/scripts/Effects.Space.cs.

| File | Set | Grid | Frames |
|---|---|---|---|
| explosion_big.png | Explosion02HD | 5x5 | 25, fireball to smoke, alpha |
| explosion_small.png | Explosion01 | 5x5 | 25, small blast to dark smoke, alpha |
| fireball_loop.png | FireBall02 | 8x8 | 64, looping fireball, no alpha (drawn additive) |
| cloud.png | Cloud02 | 8x8 | 64, billowing grey cloud, alpha |
| wisp.png | WispySmoke02 | 8x8 | 64, wispy smoke, alpha |
